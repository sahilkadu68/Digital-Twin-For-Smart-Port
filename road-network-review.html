Method, limits & offline help

Leaflet 1.9.4 is loaded from jsDelivr. The optional basemap uses OpenStreetMap tiles and sends tile requests for the viewed area; selected GeoJSON content is not uploaded. Basemap-free mode is the default and makes no tile requests. It uses a neutral background, a longitude/latitude grid, a metric scale bar and a cursor coordinate readout. The toolbar button removes optional tiles immediately. Request errors automatically disable tiles; policy-block images returned with a successful HTTP status cannot be detected reliably. Optional tiles are faint and remain beneath the roads. Road lines use all original coordinate positions with Leaflet simplification disabled (smoothFactor: 0). Display colours and overlays do not alter the source objects.

If Leaflet or its stylesheet is unavailable, a local SVG overview retains road selection, class toggles, statistics, search and candidate details. The SVG fallback also includes coordinate guides, a cursor readout and an approximate local metric scale. Pan/zoom and candidate popups require Leaflet; restore access to cdn.jsdelivr.net and reload. No server, package install, file write, geometry repair or application integration is used.

Crossing lines do not establish junctions. Private roads, dead ends, tunnels, bridges and separate carriageways require manual interpretation. No new network-break detection or traffic simulation is performed.
